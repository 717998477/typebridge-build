# TypeBridge TV（安卓输入法版）

手机当"遥控键盘"：把文字/语音直接送进**电视（安卓电视 / 电视盒子）的任意输入框**——
搜索框、WiFi 密码、账号登录、片名搜索都能用。电视端以**安卓输入法**形式存在：
在输入框里把输入法切到「TypeBridge 远程输入」，手机发送的文字就直接进入当前输入框。

与 Windows 版 TypeBridge 协议互通：手机端控制页、连接码、WebSocket 全部同一套。

## 使用步骤（电视端）

1. **安装 APK**：把 `TypeBridgeTV.apk` 拷贝到 U 盘，插到电视/盒子安装
   （电视需允许"未知来源"：设置 → 安全 → 允许安装未知来源应用）。
2. **打开应用**：屏幕显示连接码（默认 `cdhwan`）、手机访问地址
   （`http://<电视IP>:端口/m?code=连接码`）和二维码。可点
   「连接码设置… / 端口设置…」自定义（连接码 1-30 位英文/数字、端口 1-65535），
   也可点「重新生成连接码」随机更换，设置自动保存。
3. **启用输入法**：点应用里的「启用 / 切换输入法」进入系统输入法设置，
   勾选 **TypeBridge 远程输入**，设为默认输入法或记住选择。
4. 打开电视上一个需要输入的地方（如搜索框、WiFi 密码框），
   弹出输入法选择时选 **TypeBridge 远程输入**。

## 使用步骤（手机端）

1. 手机连**同一个 WiFi**（电视与手机在同一局域网）。
2. 浏览器打开电视屏幕上显示的地址（或扫屏幕上的二维码）。
3. 输入连接码（默认 `cdhwan`），出现绿点"已连接"。
4. 打字或语音输入：**手动发送**=点"发送"后上屏；**实时同步**=边说边上屏。
   支持回车、退格、撤回。

## 特性

- 纯 Java、零运行时第三方依赖（仅 ZXing 用于二维码，已打进 APK）
- 极简 HTTP + WebSocket 服务器内置，**端口可自定义**（应用内「端口设置…」，改完自动重启服务）
- **连接码可自定义**（应用内「连接码设置…」，1-30 位英文/数字，或一键随机生成），设置自动保存、重启不丢
- 连接码防爆破：同一来源连错 5 次拉黑 10 分钟
- minSdk 19（Android 4.4+），覆盖安卓电视 / 盒子 / 手机（含老款 4.4 盒子）
- APK 仅约 260KB

## 自己编译

需要 JDK 8+ 与 Android SDK（platform 30 + build-tools 30.0.3）：

```bash
bash build.sh     # 产出 TypeBridgeTV.apk（自带签名 keystore：tb.keystore）
```

说明：输入法服务 = `TbImeService`（commitText 注入），服务端 = `HttpServer`
（HTTP/WS，协议与 Windows 版一致），主界面 = `MainActivity`（连接码/IP/二维码）。

## 已知限制

- 需电视与手机同一局域网；远程组网（EasyTier）暂未接入，后续可加。
- 部分电视盒子对第三方输入法的兼容性不同，若切换后输入法不显示状态条，
  多数情况下直接打字依然生效（commitText 与界面显示无关）。
