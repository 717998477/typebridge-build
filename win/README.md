# TypeBridge 跨屏输入

手机打字 / 语音 → 电脑光标处直接出字，不用传文件、不用装驱动。

## 为什么做

在电脑上打字/发消息时，最烦的是从电脑切到手机（或反过来）。TypeBridge 让手机变成一个"无线键盘 + 语音输入器"：手机连电脑同一个 WiFi，扫码配对，手机输入法的文字/语音直达电脑光标处。**同一 WiFi 之外，电脑和手机装 EasyTier 组网后，跨公网也能用**（v0.4 起支持）。

## 版本

- **Windows 版**：`src/TypeBridge.cs`（C#5，无需第三方依赖），右下角托盘常驻，托盘菜单可弹出扫码二维码窗口、连接码设置、暂停注入、端口设置、查看连接地址、开机自启、查看日志。
- **麒麟版**：`kylin/typebridge.py`（Python3 标准库），`kylin/install.sh` 一键安装（全程自动、零输入，创建桌面图标和开机自启）。

## 怎么用

1. 电脑和手机连同一个 WiFi（或在两端装 EasyTier 组网，见下节）。
2. Windows：双击 `build/TypeBridge.exe`，自动弹出扫码窗口；麒麟：运行安装脚本后双击桌面图标。
3. 配对页会列出电脑上**所有可用网卡地址**（无线/有线/EasyTier 虚拟网卡），每张地址一个二维码；手机浏览器扫对应二维码（或直接输连接码），出现绿点"已连接"。
4. 手机上有两种模式：
   - **手动发送**：打完字点"发送"，文字到电脑光标处。
   - **实时同步**：边说边到电脑，停顿 1.5 秒自动清空输入框，方便继续说下一句（可关闭）。
   - 支持回车、退格、撤回；支持中文输入法语音输入。

## EasyTier 远程使用（不在同一路由器时）

原理：EasyTier 是一个去中心化异地组网工具，电脑和手机各自装好后加入**同一个虚拟网络**，两端会各获得一个虚拟 IP，即使不在同一 WiFi/路由器，也能通过虚拟 IP 互相访问。TypeBridge 服务本身就监听 `0.0.0.0`，组网后配对页出现「EasyTier 虚拟网卡」二维码即可扫码使用，无需改任何配置。

步骤：

1. **电脑**：安装 EasyTier 客户端（[easytier.cn](https://easytier.cn) 下载，Windows 有 GUI 客户端），启动并加入一个虚拟网络（自定义网络名 + 网络密钥）。
2. **手机**：安装 EasyTier App（Android 官方支持；iPhone 用 WireGuard 客户端接入），加入**同一个网络名/密钥**的虚拟网络。
3. 两端都显示已连接后，重新打开电脑上 TypeBridge 的配对窗口（托盘「链接二维码」），扫「EasyTier 虚拟网卡」那个二维码即可。
4. 若连不上，检查：Windows 防火墙需放行 `TypeBridge.exe`（首次运行弹出授权时选「专用网络」即可）；EasyTier 节点间 NAT 穿透失败时会自动走共享节点中转，无需手动配置。

命令行组网示例（两端命令相同，网络名/密钥一致即可）：

```
easytier-core -d --network-name mynet --network-secret mypass -p tcp://public.easytier.cn:11010
```

## 端口自定义（v0.4）

默认端口 8765，三种方式改：

- **托盘菜单 →「端口设置…」**：输入新端口，自动重启生效；
- **命令行**：`TypeBridge.exe /port 8899`（也支持 `/port:8899`、`--port=8899`、`-port 8899`）；
- **配置文件**：`%LOCALAPPDATA%\TypeBridge\config.json` 里改 `"port"`。

优先级：命令行参数 > 配置文件 > 默认 8765。改端口后，配对页二维码和手机连接地址会同步变化，手机需要重新扫码。

## 连接码（v0.4.5，自定义）

默认连接码 `cdhwan`，可自定义：仅**英文和数字**组合、**1 - 30 位**。改法：托盘菜单 →「连接码设置…」输入新连接码 → 确定，立即生效（手机需重新扫码）。也可直接编辑 `config.json` 的 `code` 字段。配对时大小写不敏感。

## 注入模式（v0.4.4，解决中文变成小格子）

部分机器默认键盘布局是「美式键盘(ENG)」时，直接注入 Unicode 会被系统改坏，目标程序里中文显示成 □□ 小格子（手动切到「简体中文 微软拼音」后就正常）。托盘菜单「注入模式」二选一（配置保存在 `config.json` 的 `injectMode`，重启后仍生效）：

- **智能（自动切换中文输入法，默认，v0.4.4）**：注入瞬间自动把前台窗口输入法切到简体中文（微软拼音），等生效后注入；**空闲 800ms / 焦点切到其他窗口 / 程序退出时自动恢复原布局**。全程无需手动操作，系统布局不留痕。绝大多数"中文变格子"用这个就好。
- **标准（直接注入）**：原始 Unicode 直发，输入法正常时最快。

切换后不用重启，托盘气泡提示当前模式；每次注入与模式切换都会写进 `log.txt`。

## 自己编译

Windows（需要 .NET Framework 4.x，系统自带 csc）：

```bat
build\build_stage1.bat
```

麒麟：直接 `python3 kylin/typebridge.py` 运行，或 `bash kylin/install.sh` 一键安装。

## 目录结构

```

build/        编译好的 Windows 程序 + 编译脚本

```

## 说明

- 端口 8765（可自定义），通信只在局域网或 EasyTier 虚拟网内进行，数据不经过任何服务器。
- 连接码默认 `cdhwan`（可自定义：英文+数字，1-30 位），防止同一 WiFi 下其他人误连；同一来源连续 5 次输错会被拉黑 10 分钟（v0.4）。
- 开机自启只在首次运行时询问一次，之后可在托盘菜单随时开关（v0.4）。
